JobMatch AI

Job search that ranks openings for you

Pulls India openings from public Greenhouse and Lever boards into an hourly-refreshed index, then ranks them against your profile with TF-IDF cosine similarity. A Groq-powered assistant uses function calling to filter by location and internships, and it remembers the conversation.

  • Deployed with Docker on Render
  • 5 automated tests

Python, FastAPI, SQLite, Groq API

Live demoGitHub

Sales Inbox Agent

An LLM that turns a sales inbox into a task list

Classifies emails, routes them to tasks and ranks priority using few-shot prompts and structured JSON output. It answers questions over saved tasks with SQL, skips duplicate emails, retries failures, and falls back to a rule-based classifier.

  • 91.7% accuracy on a 12-email synthetic set (rule-based fallback)
  • 8 automated tests

Python, FastAPI, SQLite, Gemini API

Live demoGitHub
